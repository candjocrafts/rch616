# Financial-Services AI Marketing RFP/RFI Skill Package

A self-contained, services-led IBM Consulting workflow for responding to financial-services AI-enabled marketing RFIs, RFPs, questionnaires, and due-diligence requests.

## Package map
- `SKILL.md` — operational instructions, guardrails, workflow, and outputs.
- `references/response-playbook.md` — positioning and response patterns.
- `references/bid-no-bid-and-clarification-guide.md` — decision and question discipline.
- `references/responsible-ai-and-fs-marketing-controls.md` — control prompts and safe language.
- `references/validation-gates.md` — gate criteria, red-team prompts, final QA.
- `templates/` — copy-ready intake, ledger, decision, draft, traceability, and QA files.

## Use
1. Read `SKILL.md`, then create a working response folder from the templates.
2. Preserve client requirements verbatim in the ledger and record their source locations.
3. Keep internal evidence/approval material separate from client-ready content.
4. Do not submit any draft with unresolved validation tags or unapproved claims.

This package contains no client-specific assertions, IBM credentials, rates, or commercial commitments.
